# Laglogoar

Legg logo-/ikonfiler for laga i denne mappa og oppdater `data/team-logos.json`.

Tilrådd:
- PNG, SVG eller WebP med transparent bakgrunn
- kvadratisk format
- filnamn med små bokstavar utan mellomrom, til dømes `brattvag.png`

Døme i `data/team-logos.json`:

```json
{
  "logos": {
    "Brattvåg": "assets/team-logos/brattvag.png"
  }
}
```

GitHub Pages er offentleg, men berre brukarar med skrivetilgang til repositoryet kan laste opp eller endre desse filene.
